GoAwayBCA Beta 4 dependencies

The application bundles its Python runtimes and filesystem/image helpers. End users do not need to install Python, a compiler, a package manager or a filesystem kernel extension.

Components include CPython 3.7.17 (legacy host profile), CPython 3.11.17 from python-build-standalone (modern host profile), NTFS-3G/ntfsprogs 2026.9.28, wimlib 1.14.5, hivex 1.3.24, 7-Zip 26.04, innoextract 1.9, Boost 1.83.0 and xz/liblzma 5.8.2. EFI filesystem support includes OpenNtfsDxe from OpenCore and the separately attributed EfiFs-based driver. This does not install or replace OpenCore itself.

Original third-party licences and notices are retained with the corresponding components. See ThirdParty and the dependency-source materials. Third-party software keeps its own licences; the project's GPLv3 licence does not replace them. Additional libraries bundled in the Python distributions have their own notices.

The matching release source and pinned dependency inputs describe how the application is assembled. The release retains the tested helper and firmware binaries. Reproducing those dependencies with a different compiler may yield different binary hashes; compilation target versions alone do not establish successful operation on every macOS release.
