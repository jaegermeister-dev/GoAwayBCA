# Reporting a problem

Open an issue at https://github.com/jaegermeister-dev/GoAwayBCA/issues.

Include:

1. GoAwayBCA version and macOS version used to run it.
2. Mac model identifier and any relevant storage replacement or adapter.
3. Exact Windows version, edition, architecture and ISO build; whether the image was modified.
4. Drive model, logical-sector size if known, partition layout and available space.
5. What you selected, the exact error, and the last successful step.
6. Existing Windows/other OS installations, how they were installed, and installation order.
7. Whether setup and driver installation completed, and what happened after restarting.
8. OpenCore version if used, entries visible in each startup picker, and results with the native Option/Alt picker and OpenCore where available.
9. For Linux coexistence: distribution/version, bootloader/version, installation method/order and what still boots.

Attach the saved log and GoAwayBCA diagnostic/hardware report. The app collects much of this information automatically, but supplement anything missing or unknown. Photos of an exact boot error can also help.

Review all reports for personal information before posting them. Never post passwords, private keys or a complete disk image. Reports are not uploaded automatically.

A community report is evidence about that particular configuration, not proof that every matching model behaves identically. T1 reports may be considered without a guarantee of a fix. T2-specific support is not provided.
